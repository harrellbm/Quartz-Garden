> [!summary] The Big Idea
> The current set up that I am using to sync my obsidian notes from my phone to computer and backup. 

Related Notes:
-  [[iPhone Shells and Automation]]

* * *

First I have a GitHub repository that I have all of my notes backed up to. This also acts as the source fir pushing and pulling updates from my desktop, laptop and phone.

Next on my phone I have an app named Polygit that I use to pull and push notes from the GitHub repo onto my phone itself. 

A restriction of the app is that it stores the pulled files in a specific folder that cannot be renamed. So to work around that I made two shortcuts to move the files from the polygit file to the correct folder for Obsidian to read it on my phone.  
	- [Backup Obsidian Shortcut ](https://www.icloud.com/shortcuts/876df87bb53741ddb21d261b06d41f6c)- This copies from obsidian to polygit
	- [Update Obsidian Shortcut](https://www.icloud.com/shortcuts/a49795bf55764a56a40599a42bdf1083)- This copies from polygit to obsidian

This setup has worked well so far and I like to manually review the things that are getting ready to push to the GitHub repo to make sure that they are the changes I want to save.
