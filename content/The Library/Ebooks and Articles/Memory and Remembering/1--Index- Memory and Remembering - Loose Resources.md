# PDF Readings

## Articles

- [Verbatim Memory Tool for Memorizing Paul’s Epistle to the Ephesians](Verbatim%20Memory%20Tool%20for%20Memorizing%20Paul’s%20Epistle%20to%20the%20Ephesians) by Donald L. Potter Interesting introduction around memory and memory function. Also lays out a first letter system. From my perspective it is an interesting idea but not very scalable.
- [Learn the Art of Memory](Learn%20the%20Art%20of%20Memory) from artofmemory.com. Basic run through of common memory techniques.
- [MayesLociCommunesATheologiansBestFriend.pdf](MayesLociCommunesATheologiansBestFriend.pdf) from Logia CTSFW Journal. Interesting look at the practice of common place books during the Lutheran age of orthodoxy. Seems like a master class in logical organization but definitely leaves out a lot of the complexity of the real world and poetry.
